## 阶段 3：Message 类（5 步）

- [x] 3.1 项目右键 → 添加 → 新建项 → 头文件 `Message.h`
- [x] 3.2 头文件里写 `#pragma once`，`#include <string>`
- [x] 3.3 声明成员：`std::string content_;`（消息内容）、`std::string timestamp_;`（生成时间）
- [x] 3.4 写构造函数 `explicit Message(const std::string& content)`，在构造函数里用 `std::chrono::system_clock::now()` + `std::put_time` 生成 `YYYY-MM-DD HH:MM:SS`（需要 `<chrono>`、`<iomanip>`、`<sstream>`）
- [x] 3.5 写只读访问器 `const std::string& GetContent() const;`、`const std::string& GetTimestamp() const;`

## 阶段 4：Node 抽象基类（4 步）

- [x] 4.1 新建 `Node.h`
- [x] 4.2 声明构造函数 `explicit Node(const std::string& name)`，成员 `std::string name_` 和 `bool initialized_ = false`
- [x] 4.3 写 `const std::string& GetName() const`、`bool IsInitialized() const`
- [x] 4.4 声明纯虚函数 `virtual void Init() = 0;`、`virtual void Shutdown() = 0;`；析构函数写成 `virtual ~Node() = default;`（关键：不加 virtual 会内存泄漏）
- [x] 4.5 顺便写空名检查：构造函数里 `if (name.empty()) throw std::invalid_argument("节点名不能为空");`（需要 `<stdexcept>`）
- [x] 4.6 【提交】 提交 `feat: 实现 Node 抽象基类`

## 阶段 5：ROS 单例核心（8 步，最重要）

- [x] 5.1 新建 `ROS.h`，前置声明 `class Publisher; class Subscriber; class Message;`（**只前置声明，不要在 ROS.h 里 include 它们，否则循环包含**）
- [x] 5.2 声明单例入口 `static ROS& GetInstance();`
- [x] 5.3 私有化构造函数、析构函数，并 `ROS(const ROS&) = delete;`、`operator=` 也 delete
- [x] 5.4 声明两张表：`std::map<std::string, std::vector<Publisher*>> publishers_;`、`std::map<std::string, std::vector<Subscriber*>> subscribers_;`
- [x] 5.5 新建 `ROS.cpp`，实现单例：函数内 `static ROS instance; return instance;`（Meyers 单例，线程安全）
- [x] 5.6 写注册接口 `void RegisterPublisher(const std::string& topic, Publisher* p);`、`void RegisterSubscriber(const std::string& topic, Subscriber* s);`，里面做「重名/空话题」检查
- [x] 5.7 写转发接口 `void Publish(const std::string& topic, const Message& msg);`——按话题查出所有订阅者，逐个调用其回调；话题不存在时打 WARN 日志而不是崩溃
- [x] 5.8 写 `void ShutdownAll();` 遍历所有节点调用 `Shutdown()` 并清空两张表
- [x] 5.9 【提交】 提交 `feat: 实现 ROS 单例核心（注册与消息转发）`

## 阶段 6：Publisher（5 步）

- [x] 6.1 新建 `Publisher.h`，`class Publisher : public Node`
- [x] 6.2 构造函数带 `topic` 参数，保存 `std::string topic_`

- [x] 6.4 实现 `Publish(const std::string& data)`：构造 `Message msg(data);` 再调 `ROS::GetInstance().Publish(topic_, msg);`，并打一条日志
- [x] 6.5 新建 `Publisher.cpp`，实现上面三个函数；`Shutdown()` 里打印注销日志
- [x] 6.6 【提交】 提交 `feat: 实现 Publisher 发布者`
